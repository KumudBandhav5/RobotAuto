# RobotAuto - SauceDemo Automation Framework

## Overview

RobotAuto is a web automation framework developed using:

- Robot Framework
- SeleniumLibrary
- Python
- Chrome Browser
- Git & GitHub

The framework automates real-time user scenarios on SauceDemo and follows scalable automation framework practices.

---

# Features

## Implemented Test Scenarios

- Validate Successful Login
- Validate Add Product To Cart
- Validate Checkout Flow
- Validate Order Completion
- Validate Logout Functionality

---

# Framework Features

- Reusable Keywords
- Separate Locator Management
- Variable Management
- Explicit Wait Handling
- Assertions & Validations
- Timestamp-Based Reporting
- Browser Popup Handling
- Chrome Browser Configuration
- GitHub Version Control Integration
